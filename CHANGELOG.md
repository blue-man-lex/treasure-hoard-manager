# Changelog - Treasure Hoard Manager

## [1.14.0] - 2026-07-24

### ✨ Новые возможности

#### 🪦 Corpse Looting System (D&D 5e только)
- **Автоматическая конвертация мертвых NPC в лутабельные контейнеры**
  - Определение смерти по HP ≤ 0 или статусу "dead"
  - Автоматическое создание THM контейнера при смерти
  - Только для NPC с инвентарем или валютой
  
- **Гибкие настройки** (доступны в Module Settings):
  - `Enable Corpse Looting` - включение/выключение функции (по умолчанию выкл)
  - `Auto-notify about corpses` - уведомление игроков в чате при смерти NPC
  - `Delete empty corpses` - автоудаление токенов пустых трупов (по умолчанию вкл)
  - `Corpse visual effects` - визуальные эффекты (серый оттенок, прозрачность)
  - `Corpse decay time` - время до исчезновения трупа в часах (0 = никогда)

- **Умная система отслеживания**:
  - Хуки на `updateActor` и `deleteActiveEffect`
  - Защита от повторной обработки
  - Поддержка воскрешения (автоматическое удаление флагов трупа)
  
- **Визуальная индикация**:
  - Изменение внешнего вида токена (опционально)
  - Удаление HP bar у трупов
  - Блокировка вращения токена

- **Логирование обыска**:
  - Кто и когда обыскивал труп
  - Флаги для отслеживания состояния
  - Данные о времени смерти

### ⚠️ Важно

- **Только GM обрабатывает конвертацию** - игроки только обыскивают
- **Обратная совместимость** - модуль продолжает работать на Foundry v12-v13
