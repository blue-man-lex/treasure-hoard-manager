# 🪦 Система Трупов - Руководство по использованию

## ✅ Что было исправлено

### Проблема
При включении эффекта "Труп" (Corpse) окно с сундуком открывалось, но система **НЕ отслеживала** изменения токенов, потому что хук `updateToken` не вызывал `corpse-manager`.

### Решение
**Добавлен вызов** `corpse-manager.handleTokenUpdate()` в хук `updateToken` в файле `ui-manager.js` (строки 630-633):

```javascript
// Обработка изменений токенов для corpse-manager
if (this.mainManager?.corpseManager) {
  this.mainManager.corpseManager.handleTokenUpdate(token, updateData);
}
```

## 🎮 Как использовать систему

### 1. Активация системы (только GM)
В настройках модуля **Treasure Hoard Manager** включите:
- ☑️ **Enable Corpse System** - основная система трупов
- ☑️ **Enable Corpse Decay** - автоматическое разложение (опционально)

### 2. Создание трупа

#### Способ 1: Через эффект "Corpse"
1. Выберите актера (NPC, который должен стать трупом)
2. В листе персонажа добавьте **Active Effect**:
   - **Label**: `Corpse` (или русский перевод)
   - **Icon**: любая иконка черепа/трупа
   - **Origin**: можете оставить пустым
3. **Сохраните эффект**
4. Поместите токен актера на карту

**Система автоматически:**
- ✅ Обнаружит эффект "Corpse"
- ✅ Конвертирует актера в труп-контейнер
- ✅ Откроет окно контейнера для GM
- ✅ Позволит складывать/забирать предметы

#### Способ 2: Программно (для макросов/модулей)
```javascript
// Найти актера
const actor = game.actors.getName("Goblin");

// Добавить эффект
await actor.createEmbeddedDocuments("ActiveEffect", [{
  name: "Corpse",
  icon: "icons/svg/skull.svg",
  origin: actor.uuid
}]);
```

### 3. Работа с трупом

#### Добавление предметов в труп
- Перетащите предметы из инвентаря в окно контейнера трупа
- Или используйте стандартные механики Foundry

#### Забирание предметов из трупа
- Игроки (если есть права) могут открыть контейнер
- Перетаскивать предметы к себе в инвентарь

#### Разложение трупа (если включено)
- По умолчанию: **24 часа** игрового времени
- Настраивается в параметрах модуля
- При разложении:
  - Предметы НЕ исчезают (можно изменить в настройках)
  - Показывается уведомление GM
  - Токен можно удалить вручную

## 🔧 Настройки системы

### Основные параметры
```
Enable Corpse System: true          # Включить систему трупов
Enable Corpse Decay: true           # Включить разложение
Corpse Decay Time: 24               # Время до разложения (часы)
Corpse Decay Warning Time: 23       # Предупреждение перед разложением
```

### Доступ к трупам
- **GM**: полный доступ всегда
- **Игроки**: по умолчанию НЕТ доступа (настраивается через права Foundry)

## 🐛 Тестирование

### Сценарий 1: Создание трупа
1. ✅ Создайте NPC актера с именем "Test Goblin"
2. ✅ Добавьте эффект "Corpse"
3. ✅ Поместите токен на карту
4. ✅ **Проверка**: Должно открыться окно контейнера
5. ✅ В консоли должны быть логи:
   ```
   THM Corpse Manager | Processing effect: Corpse
   THM Corpse Manager | Creating new corpse for Test Goblin
   ```

### Сценарий 2: Обновление токена
1. ✅ Переместите токен трупа
2. ✅ В консоли должен быть лог:
   ```
   THM Corpse Manager | Token update detected
   ```
3. ✅ Система должна проверить наличие эффекта "Corpse"

### Сценарий 3: Разложение (если включено)
1. ✅ Подождите или измените время разложения на 1 минуту для теста
2. ✅ Через указанное время должно появиться уведомление
3. ✅ В консоли:
   ```
   THM Corpse Manager | Checking corpse decay...
   Труп Test Goblin разложился
   ```

```javascript
game.actors.getName("Test Goblin").effects.contents

// Форсировать проверку разложения (только GM)
game.treasureHoard?.corpseManager?.checkCorpseDecay()
```

### Проблемы и решения

#### Окно не открывается
- ✅ Проверьте: эффект точно называется "Corpse"?
- ✅ Проверьте: вы GM?
- ✅ Проверьте консоль на ошибки

#### Хук не срабатывает
- ✅ Перезапустите Foundry
- ✅ Проверьте, что модуль активирован
- ✅ Проверьте логи: `THM Corpse Manager | Initialized`

#### Разложение не работает
- ✅ Проверьте настройки: **Enable Corpse Decay** включено?
- ✅ Проверьте: вы GM?
- ✅ Таймер запускается через 60 секунд после загрузки
